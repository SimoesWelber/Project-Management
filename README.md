# INCA - INGENIA Cuniculus Aprobation

**A comprehensive web-based platform for managing technical engineering document reviews**

## Overview

INCA (INGENIA Cuniculus Aprobation) is a specialized project management system designed to handle the end-to-end workflow of technical engineering document reviews for the São Paulo Metro (Companhia do Metropolitano de São Paulo) expansion projects.

The platform facilitates document submission, review workflows, approval processes, and tracking for subway stations and tunnel construction management projects.
